# Руководство Мастера

## Запуск

Установите полный release по корневому README. Включите плагин в настольном Obsidian. В настройках TaleBridge:

1. Нажмите «Создать новый код» в разделе Мастера и сохраните показанный код. Он отображается один раз; на сервере хранится hash.
2. Убедитесь, что игровые персонажи отмечены `playable: true` или тегами `player` / `игрок`.
3. Создайте код каждого игрока в списке персонажей. Каждый код привязан к стабильному ID персонажа.
4. В TaleSpire откройте симбиот TaleBridge. В окне подключения выберите роль Мастера, адрес `127.0.0.1`, порт `30123` и код.
5. Оставьте клиент Мастера в TaleSpire подключенным: он выполняет броски и команды камеры для браузерных клиентов.

Дополнительный браузерный пульт GM открывается по `http://127.0.0.1:30123/` с тем же кодом. Команды Obsidian позволяют открыть браузер, обновить персонажей/сцены, выбрать закладку камеры и отозвать подключения. Кнопки `dnd-action` отправляют броски через подключенный TaleSpire Мастера.

## Подключение игроков

По умолчанию сервер слушает только loopback. Для игры по LAN/VPN включите «Разрешить подключения по локальной сети» и перезапустите плагин. Дайте игроку адрес `http://<IP GM>:<порт>/` и его личный код. Брандмауэр должен разрешать выбранный TCP-порт только для нужной сети.

Для публичного сервера используйте HTTPS reverse proxy с поддержкой WebSocket upgrade `/ws`. Добавьте точный публичный origin в настройки плагина. Пример: страница и WebSocket через один `https://game.example` / `wss://game.example/ws`. В клиенте укажите HTTPS-адрес и соответствующий порт. Настройку proxy проверяйте в вашей инфраструктуре; встроенный сервер сам не выпускает TLS-сертификаты.

При изменении порта, интерфейса или origin перезапустите плагин. Новые коды и отзыв доступа применяются сразу. Перезапуск сервера завершает старые сессии; потребуется повторный вход.

## Подготовка кампании

Ориентируйтесь на примеры в `examples/starter-vault`. Сервер добавляет персонажам `talebridge_id`; перед этим сохраняет оригинал заметки в `.talebridge-backups/<campaign-id>/`. Этот ID не нужно редактировать вручную. Сцены получают комментарий `<!-- talebridge-scene:… -->`, который следует перемещать вместе со сценой.

Обычное переименование и перенос заметок Obsidian обновляют индекс. Изменение отдельного персонажа не требует полного повторного сканирования всех персонажей. Приватные тексты сцены, заметки и GM-поля не передаются игрокам.

## Бой, кубики и материалы

- Состояние боя сохраняется на хосте. При удалении или пересортировке участников активный ход сохраняется по личности участника.
- Игрок может завершить только свой ход; заменить целиком состояние боя вправе GM.
- Инициатива и death saves используют результат соответствующего запроса, а не первый произвольный бросок на доске.
- Поддерживаются суммы кубиков и целых модификаторов, например `2d6+1d4+3`. Неподдерживаемая формула отклоняется; ее часть не отбрасывается молча.
- Скрытие результатов использует параметр `quietResults` TaleSpire. Реальную видимость в текущем игровом клиенте необходимо проверить перед сессией.
- Выбирайте материалы из списка файлов или внешний HTTP(S) URL. Локальный материал выдается по отдельной ограниченной ссылке; исходный путь vault не становится общедоступным HTTP-маршрутом.
- Публикации сохраняются, поэтому архив получает свежие разрешенные ссылки после повторного подключения. Не передавайте preview-ссылки приватных материалов посторонним.

## Сохранение и восстановление

При конфликте приложение не затирает заметку автоматически. Обновите данные, сравните правки и повторите нужное изменение. Текст журнала остается в локальном черновике; его можно экспортировать из окна подключения. Там же можно выбрать поля для переноса из старого локального кэша.

Установщик сохраняет старые каталоги как `.previous-…`; `data.json` остается в каталоге плагина конкретного vault. Откат требует отключить плагин и восстановить проверенную предыдущую поставку вместе с ее совместимыми данными. Не запускайте старый клиент против нового протокола.

## Диагностика

`/health` должен вернуть JSON со статусом online, `/` — приложение. Если порт занят, измените его в настройках. При ошибке записи проверьте корректность YAML. При отсутствии кубиков/камеры проверьте роль GM и подключение симбиота в TaleSpire. Код и токен сессии не следует включать в диагностические сообщения.
