# Руководство для Гейм-Мастера (TaleBridge GM Guide)

**TaleBridge** — это мост между **Obsidian** (база знаний, сюжет, статблоки монстров и заметки персонажей) и **TaleSpire** (3D виртуальный игровой стол).

С помощью TaleBridge Гейм-Мастер может управлять сюжетом, камерой 3D-мира, боем, транслировать медиа (арты, письма, видео) на экраны игроков и держать все данные кампании в локальных Markdown-файлах.

---

## 1. Системные требования и установка

### Что требуется:
1. **Obsidian** (версия 1.4+).
2. **TaleSpire** (Steam).
3. Плагин **TaleBridge** для Obsidian (`obsidian-plugin/`).
4. Симбиот **TaleBridge** для TaleSpire (`symbiote/dist/` или `symbiote/`).

---

### Шаг 1: Установка плагина в Obsidian
1. Откройте папку вашего хранилища заметок (Vault).
2. Перейдите в скрытый каталог: `<Ваш_Vault>/.obsidian/plugins/`.
3. Создайте в нем папку `talebridge`.
4. Скопируйте файлы из каталога `obsidian-plugin/` репозитория:
   - `main.js`
   - `manifest.json`
   - `styles.css`
5. В Obsidian откройте **Настройки → Сторонние плагины** (Community plugins).
6. Нажмите кнопку **Перезагрузить** (Reload) и включите тумблер напротив **TaleBridge**.
7. Плагин автоматически запустит сервер на порту **30123** (`0.0.0.0:30123`).

---

### Шаг 2: Установка симбиота в TaleSpire
1. Найдите папку установки TaleSpire (через Steam: *ПКМ по TaleSpire → Свойства → Установленные файлы → Обзор*).
2. Перейдите по пути:
   ```
   TaleSpire/Taleweaver/Symbiotes/
   ```
   *(Если папки `Symbiotes` нет, создайте ее)*.
3. Создайте внутри папку `TaleBridge`.
4. Скопируйте в нее содержимое каталога `symbiote/` (или скомпилированного `symbiote/dist/`):
   - `index.html`
   - `manifest.json`
   - папку `dist/` (или `assets/`)
5. Запустите TaleSpire и откройте любую доску. В правом верхнем углу появится иконка симбиота **TaleBridge**.

---

## 2. Настройка сети для подключения игроков

Плагин Obsidian слушает входящие соединения на всех сетевых интерфейсах (`0.0.0.0:30123`).

### 1. Как узнать свой IP-адрес для игроков:

- **Если играете в одной локальной сети / домашнем Wi-Fi:**
  1. Нажмите `Win + R`, введите `cmd` и нажмите Enter.
  2. Введите команду: `ipconfig`
  3. Найдите строку **IPv4-адрес** (например, `192.168.1.105` или `192.168.0.12`).
  4. Передайте этот IP игрокам.

- **Если играете через Интернет (Radmin VPN, Hamachi, ZeroTier, Tailscale):**
  1. Запустите виртуальную сеть (например, бесплатный **Radmin VPN**).
  2. Создайте игровую комнату и пригласите игроков.
  3. Скопируйте ваш IP в сети Radmin (например, `26.15.89.123`).
  4. Передайте этот IP игрокам.

---

### 2. Открытие порта 30123 в брандмауэре Windows:
Чтобы Windows не блокировала подключения игроков из сети, откройте порт `30123`:

**Быстрый способ (через PowerShell от имени Администратора):**
```powershell
New-NetFirewallRule -DisplayName "TaleBridge Server" -Direction Inbound -LocalPort 30123 -Protocol TCP -Action Allow
```

## 3. Возможности Гейм-Мастера в интерфейсе

В правом верхнем углу переключите режим на **«ГМ»** (при необходимости введите мастер-пин, по умолчанию `5`).

### А. Сюжетный трекер (Вкладка «Сюжет»)
- **Сцены и POI**: список глав и комнат из ваших заметок.
- **Управление камерой**: клик по кнопке с координатами плавно переносит камеру TaleSpire в нужную точку 3D-карты.
- **Художественные зачитки**: текст описаний с возможностью быстрого копирования или вывода.
- **«Пинок Мастера» (Подсказки)**: список сюжетных зацепок и скрытых улик комнаты, которые игроки могут найти при осмотре.

### Б. Умный бестиарий и ростер (Вкладка «Ростер»)
- Карточки всех персонажей и монстров, распарсенных из Obsidian.
- **Броски атак в 1 клик**: бросок d20 и урона отправляется прямо в 3D-кубики TaleSpire.
- **Быстрый переход**: клик по кнопке заметки открывает полное описание в боковой панели.

### В. Боевой трекер (Вкладка «Бой»)
- **Добавление участников**: одним кликом добавляйте героев, союзников, нейтралов и врагов.
- **Инициатива**:
  - Кнопка броска инициативы для конкретного участника (иконка дайсов).
  - Автоматическая сортировка очереди ходов.
- **Управление здоровьем**: быстрые дельты урона/лечения (`-5`, `-1`, `+1`, `+5`).
- **Синхронизация состояний**: накладывайте состояния (Ослеплен, Опутан, Отравлен, Испуган и др.). Эффекты и штрафы автоматически синхронизируются и выводятся на лист персонажа соответствующего игрока!

### Г. Кинотеатр медиа-вещания (Media Broadcast)
- Одним кликом выводите арты NPC, карты комнат, письма и видео на экраны игроков.
- Экран игрока плавно затемняется, появляется карточка раздаточного материала с кнопкой сохранения в личный архив улик.

### Д. Скрытные броски ГМа (GM Secret Rolls)
- В шапке симбиота доступен переключатель: **«Скрытно»** / **«В открытую»**.
- При активном режиме «Скрытно» все броски кубиков из симбиота направляются в приватный лоток Мастера (`GM Dice Tray`), скрытый от взгляда игроков.
