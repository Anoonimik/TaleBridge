# TaleBridge Starter Vault Kit

Этот демонстрационный набор содержит эталонные Markdown-файлы, подготовленные для интеграции между **Obsidian** и **TaleSpire** через TaleBridge.

## Структура набора

1. **`Персонажи/Артём.md`** — Карточка игрового персонажа (PC):
   - Frontmatter со свойствами `playable: true`, `hp: 28`, `ac: 16`, `speed: 9 м`.
   - Блоки действий ````dnd-action``` (атаки оружием с формулами бросков).
   - Характеристики (СИЛ, ЛОВ, ТЕЛ, ИНТ, МУД, ХАР) для бросков проверок в лоток кубов.
   - Секции `### Инвентарь` (для интерактивного учета веса) и `### Заметки игрока` (двусторонняя синхронизация).

2. **`Бестиарий/Гоблин-Часовой.md`** — Карточка существа / монстра (NPC):
   - Тег `#бестиарий`.
   - Характеристики КД, ХП, атаки скимитаром и луком.

3. **`Сцены/Сессия 01 - Побег/01_Сцена 1 - Пробуждение в камере.md`** — Сюжетная сцена для Мастера:
   - Художественная зачитка (`### 📜 Зачитайте игрокам`) с кнопкой копирования и трансляции в чат или на экран.
   - Отыгрыш и реплики стражников (`### 🎭 Отыгрыш и реплики`).
   - Проверки навыков (`(КС 12)` / `(DC 12)`).
   - Развилки сюжета со ссылками на следующие сцены (`### 🔀 Развилки`).

## Как использовать

Скопируйте папки `Персонажи/`, `Бестиарий/` и `Сцены/` в корень вашего вольта Obsidian.
Симбиот TaleBridge автоматически распознает их и отобразит в интерфейсе.
