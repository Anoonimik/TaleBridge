# Стартовый vault TaleBridge

Три готовых игровых файла, которые можно скопировать в хранилище Obsidian:

- `Персонажи/Артём.md` — игровой персонаж: YAML, таблица характеристик, dnd-action, инвентарь и журнал.
- `Бестиарий/Гоблин-Часовой.md` — противник: характеристики и атаки.
- `Сцены/Сессия 01 - Побег/01_Сцена 1 - Пробуждение в камере.md` — сцена с callout зачитки, отыгрыша, улик, развилок и тактики.

Скопируйте папки `Персонажи`, `Бестиарий`, `Сцены` в vault. У Артёма выдайте код игрока в настройках TaleBridge. Приложение назначит собственные ID. Продолжение «Коридор стражи» — заготовка для вашей следующей сцены, отдельного файла в этом наборе нет.

Для новых данных используйте [образцы](../obsidian-templates/README.md), [руководство по заполнению](../../docs/OBSIDIAN_TEMPLATES.md) и [запросы для ИИ](../obsidian-templates/AI_PROMPTS.md). Стартовые игровые файлы отображаются в приложении; библиотека образцов содержит данные внутри блоков кода и сама карточек не создаёт.
