# Набор шаблонов TaleBridge для Obsidian

Начните с [руководства по заполнению](../../docs/OBSIDIAN_TEMPLATES.md). Здесь шесть образцов и [запросы для ИИ](AI_PROMPTS.md).

1. Откройте нужный файл «Шаблон …».
2. Скопируйте **содержимое блока Markdown**, начиная с `---` и до конца образца.
3. Создайте новую заметку по предложенному пути. Вставляйте исходный Markdown, чтобы YAML был в самом начале файла.
4. Переименуйте файл и замените примеры значениями своей кампании.
5. Проверьте результат по чек-листу руководства и в TaleBridge.

Образцы работают без дополнительных плагинов Obsidian и без обязательного использования ИИ. Внешний блок из четырёх обратных кавычек служит только для удобного копирования: в новую заметку его не вставляют.

Можно скопировать эту папку в vault как библиотеку инструкций: у файлов образцов нет собственного YAML-frontmatter, а слово «Шаблон» в имени исключает их из списка сцен. **Готовые карточки персонажей нельзя хранить как активные Markdown-шаблоны внутри vault:** сканер персонажей не исключает папку Templates. Даже `playable: false` скрывает карточку только от выбора игрока, но не от списка мастера. Храните заготовки в этих блоках или вне игрового vault.

Состав:

- `01_Шаблон игрового персонажа.md` — лист с характеристиками, атакой, инвентарём и журналом.
- `02_Шаблон NPC.md` — союзник, роль, отыгрыш и секреты мастера.
- `03_Шаблон противника.md` — характеристики и атака для трекера.
- `04_Шаблон сцены.md` — зачитка, улики, NPC, развилки и последствия.
- `05_Шаблон плана сессии.md` — план новой главы, не отображаемый как сцена.
- `06_Шаблон локации.md` — обычная справочная заметка.

Создавайте сцены отдельными файлами: их проще переставлять, редактировать с ИИ и проверять перед игрой. Материалы и изменения боя мастер публикует из интерфейса приложения; создание заметки само по себе не запускает бой и не показывает текст игрокам.
